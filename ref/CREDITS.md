# Credits

Playbox uses, or plans to use, the following. Keep this file with the firmware.

## In the firmware

- **MicroPython** 1.26. MIT licence. Copyright Damien P. George and
  contributors. (firmware/LICENSES/MicroPython-MIT.txt)
- **DaisySP**: filters, envelopes, oscillators and drum models in the sound

  Gillet. (firmware/LICENSES/DaisySP-MIT.txt)

  Raspberry Pi (Trading) Ltd. (firmware/LICENSES/pico-extras-BSD-3-Clause.txt)
- **Raspberry Pi Pico SDK**, as part of MicroPython's build. BSD 3-Clause.
- **Poppins** typeface (baked into fonts.py and bootfonts.py). SIL Open Font
  License 1.1. Copyright the Poppins Project Authors.
- **Recordings in samples/**. Public domain (CC0 1.0), from the sample set
  bundled with Sonic Pi, originally from freesound.org, Uwe Zahn (Arovane)
  and The Black Dog. Each file's source is in samples/ATTRIBUTION.md.
